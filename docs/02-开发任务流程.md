### 本阶段关键修复（实测发现的两个真 bug）

1. **播放页时序 bug**（视频停在占位图的直接原因）：
   `load()` 中 `openPart()` 在 `state='ok'` **之前**调用——彼时 `<video>` 尚未渲染（v-else 分支），
   `videoEl.value` 为 null，`el.play()` 从未执行。修复：先置 `state='ok'` + `await nextTick()` 再 `openPart()`。
2. **焦点分区缺失 bug**（D-pad 全键失灵的直接原因）：
   HomeView / MineView / SettingsView 三个页面根节点漏写 `data-focus-zone="content"`
   （App.vue 契约："每页自带内容分区"）。导致 `restore()` 初始聚焦失败 + `move()` 无焦点兜底
   找不到候选元素，按键全部静默失效。修复：三页根节点补上分区声明。
3. 诊断增强：`<video>` 补绑 `@error`（错误码 1-4 中文化 toast）+ 媒体事件 logcat 跟踪 + playurl 日志。

### 追加修复（模拟器听声/操作反馈轮次）

4. **播放页左右键被焦点引擎吞掉**（"Extended Controls 无法控制跳转"的根因）：
   `playerKeyHandler` 在焦点位于信息区/推荐卡片时把**全部方向键**让给引擎空间导航，而播放页视频区
   不可聚焦、周围无空间候选 → 左右键静默失效。修复：OSD 隐藏态**左右键无条件 seek ±10s**
   （媒体键 ±30s 同理）；上键唤 OSD；下键进入推荐卡片列；卡片列内上下/OK 才交给引擎。
   实测：878s → 右键 → 888s（精确 +10）。
5. **进度条恒为 0%**：`duration` ref 声明后从未赋值，`progressPct` 恒除 0。
   修复：`onLoadedMetadata` 赋值 `duration.value`（带 isFinite 守卫）+ timeupdate 兜底补齐。
   实测：1017s / 12942s → 填充 7.857%。
6. **无声问题**（模拟器侧）：视频链路本身正常（音频已解码、AudioFlinger 活跃），
   系媒体音量 3/15 过低——`input keyevent 24` 拉满至 15/15 后有声。TV 镜像音量读取用
   `cmd media_session volume --get --stream 3`（无 `media` 命令）。

### 实测结论（写入开发记忆）

- **Capacitor 7 WebView 的 JS console.log 默认不进 logcat**——诊断须走 CDP 远程调试通道
  （`adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>` + `Runtime.evaluate`，
  本项目配套探针脚本 `.tools/cdp-probe.mjs`）。
- 前台 `adb` 命令可能被宿主沙箱拦截，**install/截图/按键注入统一走后台任务**；
  adb server 需后台任务常驻保活，否则每条前台命令结束后 daemon 被回收出现 `device offline`。
- bilivideo.com MP4 直链在 WebView 媒体栈中**无需 Referer 即可播放**（P0 结论复验通过），
  但首次缓冲较慢（实测约 14s 起播，CDN 侧原因），属正常现象非 bug。
- `cap sync android` 的 update 阶段会被 safe-delete 超时打断（删掉 cordova-plugins/build.gradle 后中止）；
  仅改 web 资产时用 **`npx cap copy android`** 完全绕开；原生工程变更后才需要 sync + 手工补尾段。
